# 🎭 fsociety-ransomware (PoC)

> **"Our democracy has been hacked."**

This is a cybersecurity demonstration and study project inspired by the **fsociety** ecosystem (*Mr. Robot*). The purpose of this repository is purely educational, aiming to understand the encryption mechanisms and functioning of Ransomware attacks for defense purposes.

## 💻 About the Project

The script simulates the classic behavior of a modern ransomware, applying encryption algorithms to specific (simulated) directories and generating the famous personalized ransom note with the fsociety visual identity.

### Resources Studied:

* Implementation of symmetric/asymmetric encryption.

* Directory scanning mechanisms.

* Creation and display of the ransom note.
